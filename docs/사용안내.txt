슈퍼로봇대전 OG외전12옵션 패처 v20261107.7 — 시빌워 5부작 시험판

최종전 바로 전에 정치적 갈등·인질 구출·잠입·재합류로 이어지는5부작을 추가했습니다.
사전 정치 인터미션5곳, 각 전장 전후 교신과26개 교전 상대 조합의 자동 상호 대사를 포함합니다.
새 시빌워 관련 대화창330개이며, 기존 추가6개 전장의225개 발언도 유지합니다.
설득 명령을 누르지 않아도 관련 인물들이 처음 교전하면 한 번 표시됩니다.
공격 순서와 관계없습니다. 필요한 인물을 출격시키지 않으면 그 조합의 대사는 나오지 않습니다.
같은 인물의 후속 교전은 해당 화의 상황에 맞게 이어집니다.

진행 순서
원본34화 → 추가35~39화 → 원본35화(표시40화) → 베오울프41화
→ 시빌워42~46화 → 원본36화(표시47화·최종전).
기존12번 옵션 하나로 추가11개 전장을 선택합니다. 선택 항목은12개를 유지합니다.
최신 안정판은 v20261107.1이며 이번 배포는 실플레이 확인 전의 시험판입니다.

시빌워
- 각 전장 적32기, 중립 인질 수송기1기, 선택 출격12기. 기존 맵 재사용.
- 42/43/44/45화는 중계기2/2/3/2개 제압,46화는 반란 지휘부4기 제압으로 승리.
- 아군 전멸 또는 인질 수송기 격파 시 패배. 나머지 적 전멸은 필요하지 않습니다.
- 레피나의 정규 경비대는 인질 때문에 대립하고, 반란조4인은 정치 세력과 결탁합니다.
- 라미아와 추가 잠입조는42화 이후 임시 분리되어45화에 복귀합니다.
- 정규 경비대는45화 종료, 반란조는46화 종료 후 감시 조건으로 복귀합니다.
- 기존 기체·파일럿의 개조·장비·EXP·PP·격추수를 삭제하지 않습니다.
- 레몬은 액셀렌과 구출대에 남습니다. 두 사람의 자매 인연을 이어갑니다.
- 자세한 명단과 대사 전문은 시빌워5부작_대사와편성.md를 보세요.

베오울프 전장
넓은 아인스트 맵에서 초기 적32기 중 일반 아인스트30기가 베오울프 생존 중 계속 보충됩니다.
베오울프 격파 시 증원이 멈추고 승리합니다. 레지세이아와 베오울프는 재생성하지 않습니다.
기존 국지전5편의32기 편성,25인 합류·밸런스와 보상 설정을 유지합니다.

적용 방법
1. ZIP을 풀고 patcher 폴더의 EXE와 BIN을 같은 폴더에 둡니다.
2. PCSX2를 완전히 종료합니다.
3. 패처 실행 → ISO 선택 → 검사 → 옵션 선택 → 패치 적용 순서로 진행합니다.
4. 완료 후 완전히 새로 부팅하고 일반 세이브를 불러옵니다.
5.12번은34화 종료 이벤트 이전부터 켜고 모든 추가 전장을 마칠 때까지 유지하세요.
6.1번 추가25인 시나리오는 새 게임부터 같은 설정을 유지하세요.
7.이미 지난 합류·보상·전장 삽입 이벤트는 소급 실행되지 않습니다.

선택 기능
1. 25편성 분산 합류·추가 시나리오
   3화 전이 대화, 4~31화 합류. 기체 밸런스·본편 연결·관계 후속 장면 포함
2. 숨겨진 요소 자동 습득
   6·13·25·30화 보상 조건 해제. 미롱가는 양쪽 루트에서 입수
3. 3화 추가 보급 8종
   시시오 블레이드·부스트 해머와 강화파츠 6종을 각 1개 지급
4. 전투 보상: PP 2배·자금 +20%
   기존 보너스와 분배 계산 후 적용. 자금 소수점 버림
5. 적 강화
   전투 능력치 +5, 기체·무장 개조 +2, 기본 HP 2만 미만 +10%
6. 공통 무장 밸런스
   OGs 공통 무장 조정 이식. 외전 고유의 강화분 유지
7. 무장 개조비 할인
   OGs 최종 비용표: 0·1등급 동일, 10단계 88,000 / 105,600 / 176,000
8. 4화 수리·보급장치 추가
   수리장치·보급장치 각1개. 시나리오 선택과 별개로 한 번 지급
9. 30화부터 일부 기체 정비
   추가 아군6기의 무장9종 EN·탄수 소폭 개선. 기본 화력 유지
10. 3화 기체·무장 조기 입수
   빌트팔켄 L·아슈세이버·휴케바인 Mk-3 R 각1기와 무장2종. 파일럿 추가 없음
11. 휴케바인 Mk-3 R 무장 +200
   기본 장착 무장5종 공격력 +200. 조기 입수와 독립 선택, 다른 기체의 원래 무장 유지
12. 추가 전장 11편·시빌워·베오울프 [시험판]
   국지전5편·베오울프·최종전 직전 시빌워5부작. 교전 시 상호 설득 대사

베오울프 HD 추가 자료(선택)
ZIP의 textures 폴더를 PCSX2의 텍스처 검색 폴더에 합쳐 넣고 Load Textures를 켜세요.
대상은 SLPS-25836/replacements/beowulf_mk3/*.png 입니다.
OGs 제작본의 PNG27개만 담았습니다. 전체 HD팩은 포함하지 않습니다.
이미 다른 HD팩을 사용하면 동일 이름의 텍스처 중복을 확인해 주세요.
ISO 적용과 HD텍스처 설치는 별개입니다. 미설치 시 이식한 기본 게임 이미지를 사용합니다.
