# 지상·우주 루트 교차 진행 — v20261121

13번 「지상·우주 루트 교차 진행」을 독립 옵션으로 추가했습니다. 끄면 기존의 지상·우주 분기 선택을 유지합니다. 기존 1~12번의 선택은 그대로 사용할 수 있습니다.

원본 9화 종료 이전의 일반 세이브부터 13번을 켜고, 최종전까지 같은 설정을 유지해 주세요. 이미 지나간 분기 시나리오를 소급하여 다시 시작하지는 않습니다. PCSX2를 완전히 종료한 뒤 적용하고, 게임을 새로 부팅하여 일반 세이브를 불러오세요. 이전 상태 저장은 사용하지 마세요.

각 전장은 본래의 시점·등장 인물·적 배치·승패 조건을 사용합니다. 전환할 때 이미 보유한 인물과 기체의 사용 가능 상태를 정리하며, 새로운 기체나 파일럿을 강제로 지급하지 않습니다. 부대의 실제 등장은 각 전장의 원래 이벤트에 따릅니다.

## 화수와 다른 옵션

| 12번 추가 전장 | 13번 교차 진행 | 전체 전장 수 / 최종화 표시 |
|---|---|---|
| 끔 | 끔 | 36화 |
| 끔 | 켬 | 41화 |
| 켬 | 끔 | 49화 |
| 켬 | 켬 | 54화 |

13번을 켜면 원본 15화 이후의 표시 화수는 5씩 늘어납니다. 실제 시나리오 식별 번호와 합류·보상 이벤트의 기준은 원본을 유지합니다. 안내문에서 「원본 30화」처럼 표기한 화수와 화면의 표시 화수를 구분해 주세요.

12·13번을 함께 켰을 때: 원본 34화(표시 39화) → 국지전 40~44화 → 원본 35화(표시 45화) → 베오울프전 46화 → 시빌워 47~53화 → 라그나로크 54화.

12번 추가 전장은 원본 34화 종료 전에 켜고 모든 추가 전장을 마칠 때까지 유지합니다. 1번 추가 25편성 시나리오를 처음 시작하는 경우의 새 게임 조건도 종전과 같습니다.

## 편성과 보상 보존

- 부대 전환에는 원래 게임의 보유 기체·파일럿 활성 설정을 사용합니다. 육성·PP·격추수·개조·장비를 초기화하는 명령은 추가하지 않습니다.
- 양쪽 11·13·14화에 공통으로 들어 있는 동일한 보급 이벤트는 처음 한 번만 지급합니다. 11화 보급과 14화 보급은 서로 다른 이벤트이므로 각각 유지합니다. 각 전투에서 획득하는 정상적인 전투 보상도 유지합니다.
- 미선택 부대에 주던 자동 EXP·격추수·PP 성장 보정은 교차 진행에서 제외합니다. 양쪽 전투를 실제로 치르면서 얻은 성장에 보정이 다시 겹치지 않게 했습니다. 13번 OFF에서는 원래 보정을 유지합니다.
- 지상에서 이미 회수한 미롱가는 우주 측의 보충 지급을 반복하지 않습니다. 보유 기체를 다시 지급하는 원래 처리도 기존 육성과 장비를 보존하는지 확인합니다.
- 일부 추가 기체의 후반 정비는 원본 30화부터입니다. 교차 진행에서는 표시 35화 시점이 되도록 조정했습니다.
- 정신기·특수능력·강화파츠·도감의 설명 수정과 기존 추가 25편성·추가 전장 13편을 유지합니다. 정신기 SP 소모 1 옵션은 추가하지 않습니다.

## 확인 범위

패처 13옵션의 8,192개 조합과 이전 공개 버전 인식, 게임 내부의 분기 이동·편성 활성·중복 보상 방지·화수 조회·후반 정비 처리를 검사합니다. 양쪽 루트의 원래 대사와 전장 자원, 설명 연결과 능력 수치를 비교합니다.

실제 PCSX2에서 모든 전장을 끝까지 플레이하거나 화면·AI·메모리카드 입출력을 전부 확인한 것은 아닙니다. 플레이 테스트는 사용자가 진행합니다.
