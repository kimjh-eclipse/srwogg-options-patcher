# 수리·보급 장비와 후반 정비 — v20261106.5

개선안 5·6번을 선택 옵션 두 개로 추가했습니다. 기존 일곱 옵션과 각각 켜고 끌 수 있고, 새 패처의 기본값은 모두 꺼짐입니다. 원래 추천 목록의 4번인 전 무장 음성·자막 실플레이 검사는 이번 작업에 포함하지 않았습니다.

## 8번: 수리·보급장치

4화의 첫 추가 편성 합류 시점에 **수리장치와 보급장치를 각각 1개** 지급합니다. 매 인물이 합류할 때마다 지급하는 방식은 아닙니다. 둘 다 원래 게임의 환장 무장입니다. 환장 무장 목록에서 장비해 지원 역할을 구성하세요. 기존 장비의 효과나 장착 제한은 바꾸지 않습니다.

추가 시나리오를 꺼도 4화 본편 스크립트에서 같은 지급이 동작합니다. 기존 재고는 유지하고 새 장비를 각각 하나 추가합니다. 별도 저장 플래그로 반복·재로드 중복을 막습니다. 4화 이벤트를 이미 지난 세이브에 소급 지급하지 않습니다.

## 9번: 일부 추가 기체의 후반 정비

실제 사용률 통계는 없으므로, 추가 편성 중 화력이 비교적 낮거나 일부 무장 효율의 개선 여지가 있는 여섯 기체를 대상으로 정했습니다. 29화 전투 후 정비 대사를 보여 주며 **29화 클리어 후, 30화부터** 수치가 적용됩니다.

공격력·사거리·명중·기력 제한·이동 후 공격 여부·연출·무장 개조비와 상승량, 기체 HP·EN·장갑·운동성·이동력은 유지합니다. 원래 적과 기존 아군, 다른 추가 기체는 바꾸지 않습니다. 아군 전용 독립 무장과 기존 진행도 기반 정비 기능을 사용합니다.

옵션을 끄면 여섯 기체는 기존 무장을 사용합니다. 옵션을 켠 뒤 진행도 조건을 만족하면 기존 세이브에도 적용되며, 지난 정비 안내만 소급 재생하지 않습니다. 새로 합류시키거나 경험치·PP·개조값을 초기화하지 않습니다. 시나리오 옵션을 끈 상태에서도 이미 세이브에 여섯 기체가 있다면 정비 수치를 사용할 수 있습니다. 원작 동형 기체에는 적용하지 않습니다.

최대 탄수 증가가 이미 소비한 탄약을 즉시 채우지는 않습니다. 정비나 보급 시 새 최대치를 사용합니다. 새 기체·새 음성·새 공격 연출은 추가하지 않았습니다.

## 검증 범위

- 실제 게임의 장비 지급 처리로 시나리오 선택·해제 양쪽을 검사했습니다. 기존 재고에 각각 하나가 더해지고, 반복 및 저장 데이터 재로드 시 중복 지급하지 않음을 확인했습니다.
- 실제 Unit·Weap 조회 루틴으로 진행도 0·28·29·35에서 정비 전후 EN·최대 탄수·공격력을 확인했습니다.
- SHARED/IM 양쪽의 단계·무장 조회 336건, SHARED의 실제 전투용 등록 기록에서 무장 개조 보존 36건을 검사했습니다. IM은 메뉴용 마스터이므로 전투용 생성 검증은 SHARED를 사용합니다.
- 전후 저장 기록과 경험치·PP·개조 상태, 원래 무장·다른 기체·파일럿의 데이터 보존을 검사했습니다.
- 9옵션 512개 조합에서 지급 가드와 정비 데이터의 선택 상태 및 시나리오와의 독립 동작을 확인했습니다. 실제 ISO 조합 전환과 구간 백업 복원도 검사했습니다.
- 공통 무장 옵션은 확장된 마스터에서 무장 ID로 대상을 찾습니다. 전체 무장표 1,024회 비교와 공통 무장의 실제 게임 조회 648건으로, 후반 정비·공통 무장 선택이 서로 간섭하거나 다른 무장을 바꾸지 않는지 확인했습니다.

재로드 검사는 영구 저장 데이터 배열을 새 VM으로 복원하는 방식입니다. 실제 메모리카드 I/O·PCSX2 전편 플레이·지원 무장을 장비한 전투 전체의 실플레이 검증은 완료하지 않았습니다. 패치 후 완전히 새로 부팅하고 일반 세이브를 사용하세요.

기존 8옵션 256조합 및 v20261106.1~.4의 각 128조합을 인식합니다. 이전 적용본에서 검사하면 새 두 옵션은 꺼진 상태로 표시합니다. 예전 SP1 옵션을 새 지원 장비 옵션으로 해석하지 않습니다.
