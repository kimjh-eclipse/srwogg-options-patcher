# 최종전 직전 시빌워 5부작

기존12번 추가 전장 옵션에 포함된 시험판입니다. 선택 항목은12개를 유지합니다.

원본34화 → 국지전35~39화 → 원본35화(표시40화) → 베오울프41화 → 시빌워42~46화 → 원본36화(표시47화·최종전).

## 구성과 진행

- 경비대 반란조는 정치 세력과 결탁한 실제 배신 세력입니다. 레피나의 경비대는 인질 때문에 압박받으며, 처음부터 테츠야와 연극을 하는 설정이 아닙니다.
- 레몬은 액셀렌과 함께 구출대에 남습니다. 라미아·유리아·에키드나·토머스는 첫 전장 이후 잠입하고 네 번째 전장에서 복귀합니다.
- 전장마다 적32기와 중립 인질 수송기1기, 선택 출격12기입니다. 기존 지역 맵을 재사용합니다.
- 42/43/44/45화는 중계기2/2/3/2개 제압,46화는 반란 지휘부4기 제압으로 승리합니다. 남은 적 전멸은 필요하지 않습니다. 아군 전멸 또는 인질 수송기 격파는 패배입니다.
- 정치 사전 인터미션5곳과 각 전장 출격 전·후 교신, 승무원 경보와 출격 지시를 포함합니다. 별도 정비 메뉴·배경CG는 추가하지 않습니다.
- 상호 설득은 해당 두 인물의 실제 교전 때 자동으로 한 번 표시됩니다. 공격 순서와 관계없으며 설득 명령은 없습니다.26개 전장별 상대 조합입니다. 필요한 인물을 출격시키지 않으면 해당 조합의 대사는 나오지 않습니다.
- 대사로 해당 전장의 적을 바로 아군으로 바꾸지 않습니다. 정규 경비대는45화 종료 후, 반란조4인은46화 종료 후 지휘권 회수·감시 조건으로 복귀합니다. 사전 보유한 기체·파일럿의 육성을 삭제하거나 새로 지급하지 않습니다.
- 추가25인 대사는1번 옵션을 함께 켜야 모두 표시됩니다.12번만 켜도 전장과 기존 인물 중심의 공통 줄거리는 진행합니다.
- 12번은34화 종료 이전부터 전체 추가 전장을 마칠 때까지 유지하세요. 이미 전장 안에 들어간 세이브에서 옵션을 바꾸지 마세요. 진행 중 저장 상태 대신 패치 후 완전히 새로 부팅하고 전장 진입 전 일반 세이브를 사용하세요.
