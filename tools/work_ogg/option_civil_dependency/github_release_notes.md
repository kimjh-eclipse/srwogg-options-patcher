시빌워7부작과 정치 사전 장면5개에 **1번 추가 아군 옵션 의존 조건**을 적용했습니다. 1번 OFF에서 추가 인물의 응답만 남던 대사 연결 문제를, 해당 시나리오 전체의 진입 조건을 묶는 방식으로 처리했습니다.

- **12번만 ON:** 국지전5편과 베오울프전1편을 진행하고 본편 라그나로크로 연결합니다. 정치 사전 장면과 시빌워용 임시 부대 분리는 실행하지 않습니다.
- **1·12번 모두 ON:** 기존 정치 사전 장면과 시빌워7부작을 그대로 진행합니다.
- 패처에서 의존 조건을 안내하며, 1번을 자동으로 켜지 않습니다. 선택 항목은13개를 유지합니다.
- 최종화 표시를 조건에 맞춰 정리했습니다. 12번만 켜면42화(13번 ON은47화), 1·12번을 함께 켜면49화(13번 ON은54화)입니다.
- 기존 설명 수정·추가 아군·밸런스·교차 진행을 유지합니다. 1·12번 ON의 게임 데이터는 이전 버전과 같습니다.

### 적용 방법

PCSX2를 완전히 종료하고 ZIP을 푼 뒤, 같은 ZIP의 `EXE`와 `BIN`을 같은 폴더에 두세요. 기존 ISO 검사 → 선택값 확인 → 패치 적용 → 게임을 새로 부팅하여 일반 세이브로 진행합니다.

1번 추가 아군은 새 게임부터 유지해야 합니다. 뒤늦게 켜도 지나간 합류가 소급되지 않습니다. 12번은 원본34화 종료 전부터, 13번은 원본9화 종료 전부터 유지하세요. 이미 시빌워에 진입한 세이브에서 1·12번을 바꾸지 마세요. 1번 OFF 사용자는 정치 사전 장면 시작 전의 세이브부터 새 버전을 사용해 주세요.
