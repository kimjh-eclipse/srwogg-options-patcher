13번 **「지상·우주 루트 교차 진행」**을 독립 옵션으로 추가했습니다. 원본 10~14화의 양쪽 루트를 같은 시점끼리 번갈아 모두 진행할 수 있습니다. 끄면 기존 분기를 유지합니다.

- 순서: 지상 10화 → 우주 10화 → 지상 11화 → 우주 11화 → … → 지상 14화 → 우주 14화 → 원본 15화.
- 원본 15화 이후의 표시 화수는 +5입니다. 추가 전장을 끄면 전체 41화, 12번 추가 전장까지 켜면 전체 54화입니다.
- 부대 전환 시 보유 기체·파일럿의 사용 가능 상태를 정리하고 육성·PP·격추수·개조·장비를 보존합니다.
- 양쪽 루트에 공통인 동일 보급 이벤트의 중복 지급을 방지합니다. 각 전투의 정상 보상은 유지합니다.
- 교차 진행에서는 미선택 부대용 자동 EXP·격추수·PP 보정을 제외하여 실제 전투 성장과 중복되지 않게 했습니다. 13번 OFF에서는 원래 보정을 유지합니다.
- 후반 정비는 원본 30화, 교차 진행 시 표시 35화부터가 되도록 조정했습니다.
- 기존 1~12번과 설명 오류 수정을 유지하며, 정신기 SP 소모 1 옵션은 없습니다.
