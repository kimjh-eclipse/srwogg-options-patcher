[**패처·설명서·선택 HD자료 ZIP 다운로드**](https://github.com/kimjh-eclipse/srwogg-options-patcher/releases/download/v20261107.6/SRWOGG_Options_kr_v20261107.6.zip)

## 이번 시험판: 추가 전장 전후 대사

추가 전장6편에 전투 전·후 함내 장면12개와 전투 중 보고를 보강했습니다. 새 발언225개(게임 대화창226개)를 넣고 에이타·윤의 경보, 테츠야·레피나의 출격 지시와 귀환 보고를 연결했습니다. 추가25인이 모두 상호 대사에 참여합니다. 전투 전은 출격 선택 이전, 전투 후는 결과 처리 후 다음 화 이동 이전입니다. 별도 정비 메뉴나 배경CG를 추가하지 않습니다. [대사 전문](docs/intermission-six-v20261107.6.md)을 제공합니다.

## 베오울프 결전

**기존12번 옵션 하나**로 국지전5편과 베오울프전1편을 함께 선택합니다. 체크박스는12개입니다.

원본34화 → 국지전35~39화 → 원본35화(표시40화) → **베오울프전41화「푸른 늑대의 잔향」** → 원본36화(표시42화·최종전).

넓고 장애물이 적은 아인스트 공간에12기 선택 출격, 초기 적32기입니다. 아이젠10·녹헨8·리토6·게미유트6·레지세이아1·베오울프1로 구성했습니다. **베오울프 생존 중 일반 아인스트30기는 격파된 개체만 계속 보충됩니다. 베오울프 격파 시 증원 중지와 승리**이며 남은 적 전멸은 필요하지 않습니다. 레지세이아와 베오울프는 재생성하지 않습니다.

사용자가 OGs에서 제작한 기체·전용 무장6종·초상화·컷인15개 자료를 독립 이식했습니다. 기본HP135000, 베오울프 개조8/10단계, 일반 적6/8단계(적 강화OFF/ON)입니다. 기존 음성을 활용합니다. OGs 프로젝트와 ISO는 수정하지 않았습니다. [수치·전장·검증 범위](docs/beowulf-stage-v20261107.6.md)를 제공합니다.

기존5개 국지전의32기 편성·무인 보스10기와 추가25인 합류·밸런스·후속 대사를 유지합니다. 레몬·액셀렌의 인연을 포함한 추가 인물 대사는1번 옵션에 따릅니다. 본편 최종전과 결말을 보존합니다. [기존5편 전체 시나리오](docs/regional-five-v20261107.6.md)를 참고하세요.

**34화 종료 이벤트 이전부터12번을 켜고 모든 추가 전장을 마칠 때까지 유지하세요.** 이미 새 전장에 들어간 상태에서는 해제하지 마세요. 패치 후 완전히 새로 부팅하고 전장 진입 전 일반 세이브를 사용합니다.

선택 HD자료는 ZIP의 `textures/SLPS-25836/replacements/beowulf_mk3`에 PNG27개로 제공합니다. PCSX2의 텍스처 검색 폴더에 합쳐 설치하고 Load Textures를 켜세요. 전체 HD팩은 포함하지 않습니다.

## 다운로드와 사용

시험판 ZIP `SRWOGG_Options_kr_v20261107.6.zip`을 압축 해제하고 `patcher` 폴더의 EXE·BIN을 함께 사용하세요. PCSX2 종료 → ISO 선택 → 검사 → 옵션 선택 → 패치 적용 순서로 진행한 뒤 새로 부팅합니다. 이전 상태 저장 대신 일반 세이브를 사용하세요.

12개 옵션의 기본값은 모두 꺼짐입니다. v20261107.2·.3·.4·.5 적용본은12개 선택값을 모두 유지합니다. 이전11옵션 적용본에서 업데이트할 때만12번을 꺼짐으로 인식합니다. 옛 SP1 선택은 다시 노출하지 않습니다. 첫 적용 전 변경 구간만 `.v20261107.6.oggbak`에 보관하며 [처음 상태 복원]으로 최초 입력 상태로 돌아갑니다. [사용 안내](docs/사용안내.txt)를 참고하세요.

## 빌드

Windows PowerShell과 .NET Framework C# 컴파일러로 실행 파일을 빌드합니다. 해당 버전 릴리즈의 BIN을 준비하세요.

```powershell
.\build.ps1 -PackPath 'C:\Downloads\SRWOGG_Options_kr_v20261107.6\patcher\OGG_options.bin'
```

BIN의 SHA-256과4,096조합 자체검사를 실행하며 `dist`에 결과를 만듭니다. EXE 해시는 컴파일 시각에 따라 달라질 수 있습니다.

## 확인 범위와 소스

패처4096조합과 이전 적용본 인식을 점검합니다. 새 전장의 native 등록·조건 처리와 준비 생성192조건을 확인했습니다. 원래 기체·파일럿·무장·초상화·연출 자원, 추가25인 육성과 기존5개 전장을 보존합니다.

반복 증원100회·동시 격파7기·보스 격파 후 중지와 승리 판정은 맵 생성 부분을 시험용 상태로 대체하여 점검했습니다. 실제 NPC 재생성·퇴장·충돌·AI·연출·장기 보상·메모리카드 로드는 PCSX2 플레이 확인이 필요합니다. 사용자가 플레이 테스트를 진행하며 현재 배포는 시험판입니다. [검증 결과](docs/validation-v20261107.6.json)를 제공합니다.

`src`는 Windows패처, `tools/work_ogg`는 제작·분석·검증 소스입니다. 게임에서 추출한 로컬 입력과 OGs 제작본의 베오울프 자료는 저장소에 포함하지 않아 모든 제작을 이 저장소만으로 재현하지는 못합니다. 역사적 빌더를 현재 ISO에 재실행하지 마세요. [제작 도구 안내](tools/README.md)를 참고하세요.

게임ISO·BIOS·메모리 덤프·세이브·전체 ISO백업은 배포하지 않습니다.
