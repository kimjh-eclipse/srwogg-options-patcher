# OG외전 한글판 옵션 패처

슈퍼로봇대전 OG외전 한글판용 Windows 패처입니다. 일곱 가지 기능을 독립적으로 선택하고 다시 해제할 수 있습니다.

## 베이스 한글 패치

[z3oo3z/PS2-SRWOGG-KPatch](https://github.com/z3oo3z/PS2-SRWOGG-KPatch)의 **v1.4.3s**를 기준으로 합니다. [공식 릴리즈](https://github.com/z3oo3z/PS2-SRWOGG-KPatch/releases/tag/SRWOGG)의 패치를 일본판 원본(MD5 `cb7dc4485f46f220c46095c966a3aad0`)에 먼저 적용하세요. 공식 패치 결과 MD5는 `a5254cd5d4deabc57e03a3dcbb6a88d7`입니다.

제작자의 원본 한글 패치 파일은 이 저장소·릴리즈에 포함하지 않습니다. 출처와 검증값은 [베이스 정보](docs/base-patch.json)에 기록했습니다. 기존 v20261106·v20261106.1·v20261106.2·v20261106.3 적용본도 새 패처에서 지원합니다.

## 이번 업데이트 — v20261106.4

추가 시나리오를 본편 장면 순서에 맞춰 연결했습니다. 13개 화의 대사창 31개를 다듬고 최종전 반응 3개를 추가했습니다. 28화의 빈델 장면은 피오나 귀환·라미아 구출 작전 설명 뒤로, 35화의 반응은 데스피니스 구조 뒤로 옮겼습니다. 36화는 비안·잉그램·레몬의 짧은 반응을 추가하고 원작의 마지막 대사로 마칩니다. [장면별 설명과 바꾼 대사](docs/story-consistency-v20261106.4.md)를 확인하세요.

기존 1번 ‘25편성 분산 합류·추가 시나리오’ 옵션에 포함되며, 옵션을 끄면 새 대사도 선택되지 않습니다. 레몬과 액셀렌의 자매 인연, 합류 화수, 능력치·정신기·무장·비용 설정과 [1단계 정신기 조정](docs/spirit-balance-v20261106.2.md)·[2단계 편성 보존](docs/party-preservation-v20261106.3.md)은 유지합니다.

## 다운로드와 실행

[Releases](../../releases)에서 `SRWOGG_Options_kr_v20261106.4.zip`을 내려받아 압축을 해제합니다. `patcher` 폴더의 EXE와 BIN을 같은 폴더에 두고 EXE를 실행하세요. PCSX2를 종료한 뒤 ISO 선택 → 검사 → 옵션 선택 → 패치 적용 순서로 진행합니다.

처음에는 모든 옵션이 해제되어 있습니다. 기존 지형명·도움말·추가 전투 자막 등의 한글 표시 수정과 추가 파일럿 정신기 조정은 공통 적용됩니다. 기존 파일럿의 정신기는 유지합니다. SP 1 옵션은 제거했습니다. 이전 8옵션 적용본의 256가지 조합도 업데이트할 수 있습니다. 최초 적용 전에 변경 구간만 `.oggbak`에 저장하며, **처음 상태 복원**으로 되돌릴 수 있습니다.

| 옵션 | 내용 |
| --- | --- |
| 25편성·추가 시나리오 | 3화부터 전이 대화, 4~31화 분산 합류, 추가 편성 밸런스·본편 연결 대사 |
| 숨겨진 요소 자동 습득 | 6·13·25·30화 숨김 보상 조건 해제 |
| 3화 보급 | 요청한 무기·강화파츠 8종을 각각 1개 지급 |
| 전투 보상 | PP 2배, 자금 +20% |
| 적 강화 | 전투 능력치 +5, 기체·무장 개조 +2, 기본 HP 2만 미만 +10% |
| 공통 무장 밸런스 | OGs 공통 무장 27종 조정 이식 |
| 개조비 할인 | OGs 최종 비용표: 10단계 누적 0·1등급 88,000 / 2등급 105,600 / 3·4등급 176,000 |

25편성 시나리오는 새 게임에서 시작하세요. 이미 받은 보상이나 합류한 인물은 옵션을 해제해도 세이브에서 삭제되지 않습니다. 이벤트가 지난 세이브에 보급이 소급 지급되지는 않습니다. 패치 후 상태 저장을 불러오지 말고 게임을 새로 부팅하세요. 자세한 내용은 [사용 안내](docs/사용안내.txt)를 참고하세요.

## 빌드

Windows PowerShell 5.1 이상과 .NET Framework C# 컴파일러를 사용합니다. Python은 패처 실행·빌드에 필요하지 않습니다.

1. 해당 버전 릴리즈 ZIP에서 `patcher/OGG_options.bin`을 준비합니다.
2. 저장소 루트에서 실행합니다.

```powershell
.\build.ps1 -PackPath 'C:\Downloads\SRWOGG_Options_kr_v20261106.4\patcher\OGG_options.bin'
```

`dist`에 EXE와 BIN이 생성됩니다. 패치 데이터의 SHA-256과 128개 조합을 자동 검사합니다. 릴리즈 EXE와 직접 빌드한 EXE의 파일 해시는 컴파일 시각 등에 따라 다를 수 있습니다.

## 소스 구성

- `src/OggOptionsPatcher.cs`: UI, 입력 검증, 7개 옵션 합성, 구간 백업·복원, 명령행 검증.
- `build.ps1`: 패처 빌드와 자체 검사.
- `tools/work_ogg`: 패치 제작·시나리오·밸런스·한글화·분석·네이티브 검증 Python 소스.
- `tools/work_ogs`: 위 소스가 참조하는 한글 코덱과 R5900 검사기 소스.
- `docs`: 사용 안내, 패치 정보, 검증 결과.

Python 제작 도구는 작업 과정을 보존한 소스입니다. 일부 도구는 예전 단계의 파일명·중간 산출물·적용 전 상태를 전제로 하므로 현재 ISO에 그대로 순서대로 실행하면 안 됩니다. 관련 내용과 재현 범위는 [제작 도구 안내](tools/README.md)를 참고하세요.

## 검증 범위

128개 조합을 실제 시험 ISO에 적용·읽기 검사하고 구간 백업을 통해 원래 파일로 복원했습니다. 공식 베이스 557개 구간 검증도 통과했습니다. 이번 대사 수정은 이력 5,808항목, 변경 대상 외 문자열 6,873개, 실제 게임 문자열·이력 조회 106건도 확인했습니다. 편성 관련 명령 779건, 합류 가드 22개의 중복 방지와 영구 저장 데이터 재로드 4회를 검사했습니다. 맵 유닛 조회는 부재 조건의 대체 입력이고 재로드는 새 VM에 저장 데이터를 복원한 것으로, 실제 메모리카드 I/O나 전편 맵 동작 검증은 아닙니다. 실제 게임 R5900 루틴으로 보급 중복 방지, 대화 문자열·로그, 보상 계산, 적 능력치·HP 및 옵션 독립 동작을 검사했습니다. [검증 결과](docs/validation-v20261106.4.json)를 제공합니다. PCSX2에서 전편을 플레이한 검증은 하지 않았습니다.

지원 원본은 크기 `4,666,294,272`바이트이며 SHA-256은 다음과 같습니다.

```text
e819f1e524513bc7e273b004ba02e3977dd4fff365a5887b4eb1c8a9fc9d1e04
```

게임 ISO·BIOS·메모리 덤프·세이브 파일은 저장소와 릴리즈에 포함하지 않습니다. 릴리즈에는 적용에 필요한 패치 데이터만 제공합니다.
