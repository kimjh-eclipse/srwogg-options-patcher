# OG외전 한글판 옵션 패처

슈퍼로봇대전 OG외전 한글판용 Windows 패처입니다. 여덟 가지 기능을 독립적으로 선택하고 다시 해제할 수 있습니다.

## 다운로드와 실행

[Releases](../../releases)에서 `SRWOGG_Options_kr_v20261106.zip`을 내려받아 압축을 해제합니다. `patcher` 폴더의 EXE와 BIN을 같은 폴더에 두고 EXE를 실행하세요. PCSX2를 종료한 뒤 ISO 선택 → 검사 → 옵션 선택 → 패치 적용 순서로 진행합니다.

처음에는 모든 옵션이 해제되어 있습니다. 기존 지형명·도움말·추가 전투 자막 등의 한글 표시 수정은 공통으로 적용됩니다. 최초 적용 전에 변경 구간만 `.oggbak`에 저장하며, **처음 상태 복원**으로 되돌릴 수 있습니다.

| 옵션 | 내용 |
| --- | --- |
| 25편성·추가 시나리오 | 3화부터 전이 대화, 4~31화 분산 합류, 추가 편성 밸런스 |
| 숨겨진 요소 자동 습득 | 6·13·25·30화 숨김 보상 조건 해제 |
| 3화 보급 | 요청한 무기·강화파츠 8종을 각각 1개 지급 |
| 전투 보상 | PP 2배, 자금 +20% |
| 적 강화 | 전투 능력치 +5, 기체·무장 개조 +2, 기본 HP 2만 미만 +10% |
| 공통 무장 밸런스 | OGs 공통 무장 27종 조정 이식 |
| 개조비 할인 | 최저 비용표를 제외한 무장 개조비 20% 할인 |
| SP 소모 1 | 정신기 소모 SP를 1로 설정 |

25편성 시나리오는 새 게임에서 시작하세요. 이미 받은 보상이나 합류한 인물은 옵션을 해제해도 세이브에서 삭제되지 않습니다. 이벤트가 지난 세이브에 보급이 소급 지급되지는 않습니다. 패치 후 상태 저장을 불러오지 말고 게임을 새로 부팅하세요. 자세한 내용은 [사용 안내](docs/사용안내.txt)를 참고하세요.

## 빌드

Windows PowerShell 5.1 이상과 .NET Framework C# 컴파일러를 사용합니다. Python은 패처 실행·빌드에 필요하지 않습니다.

1. 해당 버전 릴리즈 ZIP에서 `patcher/OGG_options.bin`을 준비합니다.
2. 저장소 루트에서 실행합니다.

```powershell
.\build.ps1 -PackPath 'C:\Downloads\SRWOGG_Options_kr_v20261106\patcher\OGG_options.bin'
```

`dist`에 EXE와 BIN이 생성됩니다. 패치 데이터의 SHA-256과 256개 조합을 자동 검사합니다. 릴리즈 EXE와 직접 빌드한 EXE의 파일 해시는 컴파일 시각 등에 따라 다를 수 있습니다.

## 소스 구성

- `src/OggOptionsPatcher.cs`: UI, 입력 검증, 8개 옵션 합성, 구간 백업·복원, 명령행 검증.
- `build.ps1`: 패처 빌드와 자체 검사.
- `tools/work_ogg`: 패치 제작·시나리오·밸런스·한글화·분석·네이티브 검증 Python 소스.
- `tools/work_ogs`: 위 소스가 참조하는 한글 코덱과 R5900 검사기 소스.
- `docs`: 사용 안내, 패치 정보, 검증 결과.

Python 제작 도구는 작업 과정을 보존한 소스입니다. 일부 도구는 예전 단계의 파일명·중간 산출물·적용 전 상태를 전제로 하므로 현재 ISO에 그대로 순서대로 실행하면 안 됩니다. 관련 내용과 재현 범위는 [제작 도구 안내](tools/README.md)를 참고하세요.

## 검증 범위

256개 조합을 실제 시험 ISO에 적용·읽기 검사하고 구간 백업을 통해 원래 파일로 복원했습니다. 실제 게임 R5900 루틴으로 보급 중복 방지, 대화 문자열·로그, 보상 계산, 적 능력치·HP 및 옵션 독립 동작을 검사했습니다. [검증 결과](docs/validation-v20261106.json)를 제공합니다. PCSX2에서 전편을 플레이한 검증은 하지 않았습니다.

지원 원본은 크기 `4,666,294,272`바이트이며 SHA-256은 다음과 같습니다.

```text
a9f7f03c4cb722f9e0709860a1cf5a16fc52d8bf116a9458403ffc5a67fd7f63
```

게임 ISO·BIOS·메모리 덤프·세이브 파일은 저장소와 릴리즈에 포함하지 않습니다. 릴리즈에는 적용에 필요한 패치 데이터만 제공합니다.
