# OG외전 한글판 옵션 패처

슈퍼로봇대전 OG외전 한글판용 Windows 패처입니다. 열한 가지 기능을 독립적으로 선택하고 다시 해제할 수 있습니다.

## 베이스 한글 패치

[z3oo3z/PS2-SRWOGG-KPatch](https://github.com/z3oo3z/PS2-SRWOGG-KPatch)의 **v1.4.3s**를 기준으로 합니다. [공식 릴리즈](https://github.com/z3oo3z/PS2-SRWOGG-KPatch/releases/tag/SRWOGG)의 패치를 일본판 원본(MD5 `cb7dc4485f46f220c46095c966a3aad0`)에 먼저 적용하세요. 공식 패치 결과 MD5는 `a5254cd5d4deabc57e03a3dcbb6a88d7`입니다.

제작자의 원본 한글 패치 파일은 이 저장소·릴리즈에 포함하지 않습니다. 출처와 검증값은 [베이스 정보](docs/base-patch.json)에 기록했습니다. 기존 v20261106·v20261106.1·v20261106.2·v20261106.3·v20261106.4·v20261106.5 적용본도 새 패처에서 지원합니다.

## 이번 업데이트 — v20261107.1

**휴케바인 Mk-Ⅲ 타입 R을 3화에 기체만 1기 입수**하도록 추가했습니다. 10번 조기 입수에서 선택하며 기존 빌트팔켄 L·아슈세이버와 무장 2종 지급도 유지합니다. 파일럿 추가·강제 탑승은 없습니다.

별도 **11번 옵션**은 타입 R의 기본 장착 무장 5종 공격력을 각각 200 올립니다. 원래 공유 무장을 전역 수정하지 않고 타입 R용 데이터를 사용합니다. 다른 기체의 기존 무장, 사거리·EN·탄수·연출·개조비·개조 상승량과 기체 능력치는 유지합니다. [무장별 수치와 세이브 안내](docs/huckebein-R-v20261107.1.md)를 참고하세요.

이어서 25·29·31·32·36화의 기존 추가 대사 **17개**를 다듬었습니다. 잉그램과 SRX팀의 경계심, 오우카 일행의 애도, 종전 뒤의 약속을 더 자연스럽게 연결했습니다. 사건 순서·결말·합류 일정·플래그·대사 이력과 레몬·액셀렌의 자매 설정은 유지합니다. [현재 추가 대사와 수정 범위](docs/followup-story-v20261107.1.md)를 제공합니다.

총 **11개 옵션·2,048개 조합**, 기본값은 모두 꺼짐입니다. 기존 정신기·편성 보존·지원 장비·후반 정비도 유지합니다.

## 다운로드와 실행

[Releases](../../releases)에서 `SRWOGG_Options_kr_v20261107.1.zip`을 내려받아 압축을 해제합니다. `patcher` 폴더의 EXE와 BIN을 같은 폴더에 두고 EXE를 실행하세요. PCSX2를 종료한 뒤 ISO 선택 → 검사 → 옵션 선택 → 패치 적용 순서로 진행합니다.

처음에는 모든 옵션이 해제되어 있습니다. 이전 v20261107의 10옵션 적용본은 선택값을 유지하며 새 무장 +200만 꺼짐으로 인식합니다. v20261106.5 적용본의 지원 장비·정비 선택도 유지합니다. 더 오래된 7·8옵션 적용본에서는 두 기능을 꺼짐으로 인식하며, 예전 SP1 선택을 지원 장비 선택으로 바꾸지 않습니다. 기존 지형명·도움말·추가 전투 자막 등의 한글 표시 수정과 추가 파일럿 정신기 조정은 공통 적용됩니다. 기존 파일럿의 정신기는 유지합니다. SP 1 옵션은 제거했습니다. 이전 8옵션 적용본의 256가지 조합도 업데이트할 수 있습니다. 최초 적용 전에 변경 구간만 `.oggbak`에 저장하며, **처음 상태 복원**으로 되돌릴 수 있습니다.

## 빌드

Windows PowerShell 5.1 이상과 .NET Framework C# 컴파일러를 사용합니다. Python은 패처 실행·빌드에 필요하지 않습니다.

1. 해당 버전 릴리즈 ZIP에서 `patcher/OGG_options.bin`을 준비합니다.
2. 저장소 루트에서 실행합니다.

```powershell
.\build.ps1 -PackPath 'C:\Downloads\SRWOGG_Options_kr_v20261107.1\patcher\OGG_options.bin'
```

`dist`에 EXE와 BIN이 생성됩니다. 패치 데이터의 SHA-256과 2,048개 조합을 자동 검사합니다. 릴리즈 EXE와 직접 빌드한 EXE의 파일 해시는 컴파일 시각 등에 따라 다를 수 있습니다.

## 소스 구성

- `src/OggOptionsPatcher.cs`: UI, 입력 검증, 11개 옵션 합성, 구간 백업·복원, 명령행 검증.
- `build.ps1`: 패처 빌드와 자체 검사.
- `tools/work_ogg`: 패치 제작·시나리오·밸런스·한글화·분석·네이티브 검증 Python 소스.
- `tools/work_ogs`: 위 소스가 참조하는 한글 코덱과 R5900 검사기 소스.
- `docs`: 사용 안내, 패치 정보, 검증 결과.

Python 제작 도구는 작업 과정을 보존한 소스입니다. 일부 도구는 예전 단계의 파일명·중간 산출물·적용 전 상태를 전제로 하므로 현재 ISO에 그대로 순서대로 실행하면 안 됩니다. 관련 내용과 재현 범위는 [제작 도구 안내](tools/README.md)를 참고하세요.

## 검증 범위

기체만 지급, 이미 보유한 기체 상태 보존, 반복·저장 데이터 복원 후 중복 지급 방지를 실제 게임 루틴으로 확인했습니다. 타입 R의 전용 무장과 원래 공유 무장의 공격력, 무장 강화 OFF/ON 및 공통 무장 옵션과의 독립 동작도 확인했습니다. 대사 17개는 같은 대사 번호·명령 순서·이력을 유지하며 실제 문자열·이력 조회 34건을 추가 확인했습니다.

2,048개 조합을 메모리에서 합성하여 조기 입수, 강화 선택·해제 및 다른 기능 보존을 확인했습니다. 이전 v20261107의 1,024조합과 이전 버전 인식, 패처 자체 검사·저장소 빌드도 통과했습니다. [검증 결과](docs/validation-v20261107.1.json)를 제공합니다.

전체 ISO에 2,048조합을 반복 쓰지는 않았습니다. PCSX2 플레이 테스트는 사용자가 진행합니다. VM의 저장 데이터 복원은 실제 메모리카드 I/O나 전편 플레이 검증이 아닙니다.

지원 원본은 크기 `4,666,294,272`바이트이며 SHA-256은 다음과 같습니다.

```text
e819f1e524513bc7e273b004ba02e3977dd4fff365a5887b4eb1c8a9fc9d1e04
```

게임 ISO·BIOS·메모리 덤프·세이브 파일은 저장소와 릴리즈에 포함하지 않습니다. 릴리즈에는 적용에 필요한 패치 데이터만 제공합니다.
