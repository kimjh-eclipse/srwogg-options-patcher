# OG외전 한글판 옵션 패처

슈퍼로봇대전 OG외전 한글판용 Windows 패처입니다. **v20261107.2는 국지전 5편을 추가한 12옵션 시험판**이며, 최신 안정판은 [v20261107.1](https://github.com/kimjh-eclipse/srwogg-options-patcher/releases/tag/v20261107.1)입니다.

## 이번 시험판

[국지전 5편 시험판 다운로드](https://github.com/kimjh-eclipse/srwogg-options-patcher/releases/tag/v20261107.2)

**34화 → 추가35~39화 → 본래35화(표시40화) → 본래36화(표시41화·최종전)** 순서로 진행합니다. 액셀·알피미의 정식 합류 이후입니다. 기존 전장을 사용하고 보유 기체12기 선택 출격·적16기로 구성했습니다.

| 표시 화수 | 제목 | 장소 |
| --- | --- | --- |
| 35 | 철의 기억 | 인디리스크 시험장 |
| 36 | 빼앗긴 보급로 | 해안 보급기지 |
| 37 | 폐기되지 않은 이름 | 어스크레이들 인근 지하시설 |
| 38 | 닫히지 않은 침공로 | 콜로니 외곽 |
| 39 | 그림자의 귀로 | 콜무나 군수시설 |

주력의 듀미너스 추격은 유지하고 분견대가 잠시 열린 외부 통로를 왕복하는 추가 설정입니다. 원작 최종전 전투와 종료 처리는 보존합니다. 기존1번 옵션을 켜면 추가25인의 역할과 레몬·액셀렌의 자매 장면을 포함해 연결 대사130칸이 나옵니다. 1번을 끄면 본편 인물의 공통 작전 대사로 진행합니다. 기체·파일럿·물품을 중복 지급하지 않습니다. [추가 설정과 전체 대사](docs/regional-five-v20261107.2.md)를 제공합니다.

**34화 종료 이벤트 이전 일반 세이브**에서12번을 켜고 다섯 작전 동안 유지하세요. 이미 본래35화로 넘어간 세이브에는 소급 삽입되지 않습니다. PCSX2 출격·전투·결과 창·메모리카드 로드 확인은 사용자가 진행하며, 이번 배포는 시험판으로 표시합니다.

[OGGv1.4.3sta.7z 직접 다운로드](https://github.com/z3oo3z/PS2-SRWOGG-KPatch/releases/download/SRWOGG/OGGv1.4.3sta.7z)도 제공합니다.

일본판 원본 MD5는 `cb7dc4485f46f220c46095c966a3aad0`, 공식 한글패치 결과 MD5는 `a5254cd5d4deabc57e03a3dcbb6a88d7`입니다. 제작자의 원본 패치 파일은 이 저장소·릴리즈에 포함하지 않습니다. [베이스 정보](docs/base-patch.json)를 참고하세요.

## 다운로드와 사용

시험판 ZIP `SRWOGG_Options_kr_v20261107.2.zip`을 압축 해제하고 `patcher` 폴더의 EXE·BIN을 함께 사용하세요. PCSX2 종료 → ISO 선택 → 검사 → 옵션 선택 → 패치 적용 순서로 진행한 뒤 새로 부팅합니다. 이전 상태 저장 대신 일반 세이브를 사용하세요.

12개 옵션의 기본값은 모두 꺼짐입니다. v20261107.1의2,048조합을 포함한 지원 적용본은 기존 선택을 유지하고 새12번만 꺼짐으로 인식합니다. 옛 SP1 선택은 다시 노출하지 않습니다. 첫 적용 전 변경 구간만 `.v20261107.2.oggbak`에 보관하며 [처음 상태 복원]으로 최초 입력 상태로 돌아갑니다. [사용 안내](docs/사용안내.txt)를 참고하세요.

| 옵션 | 내용 |
| --- | --- |
| 25편성·추가 시나리오 | 3화 전이 대화, 4~31화 분산 합류·밸런스·후속 대사 |
| 숨겨진 요소 자동 습득 | 6·13·25·30화 숨김 보상 조건 해제 |
| 3화 보급 | 무기·강화파츠8종 각각1개 |
| 전투 보상 | PP2배·자금+20% |
| 적 강화 | 전투 능력치+5·개조+2·기본 HP2만 미만+10% |
| 공통 무장 밸런스 | OGs 공통 무장27종 조정 |
| 개조비 할인 | 10단계 누적0·1등급88,000 / 2등급105,600 / 3·4등급176,000 |
| 4화 지원 장비 | 수리·보급장치 각각1개 |
| 후반 정비 | 30화부터 추가6기·무장9종의 EN·탄수 개선 |
| 3화 조기 입수 | 빌트팔켄 L·아슈세이버·휴케바인 R, 무장2종. 파일럿 추가 없음 |
| 휴케바인 R 무장+200 | 기본 무장5종, 조기 입수와 별도 선택 |
| 34화 이후 국지전5편 | 시험판. 추가35~39화 뒤 본편40~41화 |

추가25인 시나리오는 새 게임부터 같은 설정을 유지하세요. 받은 보상·합류한 인물은 옵션을 꺼도 세이브에서 삭제되지 않으며 지난 이벤트가 소급 재생되지 않습니다. 이전 안내의35·36화는 원본 화수이고 국지전 선택 시 표시40·41화입니다.

## 빌드

Windows PowerShell과 .NET Framework C# 컴파일러로 실행 파일을 빌드합니다. 해당 버전 릴리즈의 BIN을 준비하세요.

```powershell
.\build.ps1 -PackPath 'C:\Downloads\SRWOGG_Options_kr_v20261107.2\patcher\OGG_options.bin'
```

BIN의 SHA-256과4,096조합 자체검사를 실행하며 `dist`에 결과를 만듭니다. EXE 해시는 컴파일 시각에 따라 달라질 수 있습니다.

## 확인 범위와 소스

게임 함수로 문자열·이력·제목·화수·전멸 조건·다음 화 처리를 점검했습니다. 병력 수를 입력하는 시험이며 전장 화면을 재현하지 않습니다. 영구 Save/Diff 배열을 새 VM에 복원하는7개 경로에서25인의 육성 보존을 확인했습니다. 실제 메모리카드 I/O 검증은 아닙니다.

기존186개 편성 파일과34화를 제외한42개 대사 파일, 기존 전투 마스터와 원작 최종전 종료 명령을 보존했습니다. 패처4,096조합, 메모리 내 국지전 조합57,344건과 이전 적용본 인식도 확인했습니다. ISO에4,096번 반복 적용하거나 PCSX2 전편 플레이를 검증하지 않았습니다. [검증 결과](docs/validation-v20261107.2.json)를 제공합니다.

`src`는 Windows 패처, `tools/work_ogg`는 제작·시나리오·분석·네이티브 검증 소스입니다. 게임에서 추출한 로컬 입력은 포함하지 않아 모든 제작 과정을 이 저장소만으로 재현할 수는 없습니다. 역사적 빌더를 현재 ISO에 순서대로 재실행하지 마세요. [제작 도구 안내](tools/README.md)를 참고하세요.

게임 ISO·BIOS·메모리 덤프·세이브·전체 ISO 백업은 저장소와 릴리즈에 포함하지 않습니다.
