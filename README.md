# OG외전 한글판 옵션 패처

슈퍼로봇대전 OG외전 한글판용 Windows 패처입니다. 열 가지 기능을 독립적으로 선택하고 다시 해제할 수 있습니다.

## 베이스 한글 패치

[z3oo3z/PS2-SRWOGG-KPatch](https://github.com/z3oo3z/PS2-SRWOGG-KPatch)의 **v1.4.3s**를 기준으로 합니다. [공식 릴리즈](https://github.com/z3oo3z/PS2-SRWOGG-KPatch/releases/tag/SRWOGG)의 패치를 일본판 원본(MD5 `cb7dc4485f46f220c46095c966a3aad0`)에 먼저 적용하세요. 공식 패치 결과 MD5는 `a5254cd5d4deabc57e03a3dcbb6a88d7`입니다.

제작자의 원본 한글 패치 파일은 이 저장소·릴리즈에 포함하지 않습니다. 출처와 검증값은 [베이스 정보](docs/base-patch.json)에 기록했습니다. 기존 v20261106·v20261106.1·v20261106.2·v20261106.3·v20261106.4·v20261106.5 적용본도 새 패처에서 지원합니다.

## 이번 업데이트 — v20261107

기존 추가 시나리오 옵션에 **후속 장면 5개·대사 73개**를 보강했습니다. 조기 입수 기능을 별도 10번 옵션으로 추가하여 **10개 옵션·1,024가지 조합**을 지원합니다. 기본값은 모두 꺼짐입니다.

| 화 | 추가 내용 |
| --- | --- |
| 25 | 잉그램과 SRX팀의 신뢰 회복 조건, 오우카와 아이들의 상호 돌봄 |
| 29 | 비안·류네의 다른 시간, 라미아의 자율성과 레몬·액셀렌의 자매 인연 |
| 31 | 빈델·웬드로의 조건부 공투와 책임 |
| 32 | 알티스의 죽음 뒤 이동 중 통신, 돌아온 이가 약속할 수 없는 것 |
| 36 | 증언·조사와 다음 만남을 남기는 작별 |

공투가 즉각적인 용서가 되지는 않으며, 원작의 죽음과 마지막 대사를 유지합니다. 합류 화수·능력치·정신기·무장·보상은 이번 대사 보강으로 바뀌지 않습니다. [추가 대사와 적용 안내](docs/followup-story-v20261107.md)를 확인하세요.

**10번 조기 입수**는 3화에서 빌트팔켄 타입 L·아슈세이버 각 1기, 그라비톤 런처·G 임팩트 스테이크 각 1개를 지급합니다. 파일럿 추가·강제 탑승 없이 원래 성능과 기본 무장을 사용합니다. 시나리오 및 기존 8종 보급과 독립 동작하고, 이미 보유한 동일 기체는 복제하거나 육성·개조를 초기화하지 않습니다. 해당 이벤트 이전 세이브부터 진행하세요.

이전 [지원 장비·후반 정비](docs/support-overhaul-v20261106.5.md), [정신기](docs/spirit-balance-v20261106.2.md), [편성 보존](docs/party-preservation-v20261106.3.md), [본편 연결 대사](docs/story-consistency-v20261106.4.md)도 유지합니다.

## 다운로드와 실행

[Releases](../../releases)에서 `SRWOGG_Options_kr_v20261107.zip`을 내려받아 압축을 해제합니다. `patcher` 폴더의 EXE와 BIN을 같은 폴더에 두고 EXE를 실행하세요. PCSX2를 종료한 뒤 ISO 선택 → 검사 → 옵션 선택 → 패치 적용 순서로 진행합니다.

처음에는 모든 옵션이 해제되어 있습니다. 이전 v20261106.5 적용본의 지원 장비·정비 선택을 유지하며 새 10번 조기 입수는 꺼짐으로 인식합니다. 더 오래된 7·8옵션 적용본에서는 두 기능을 꺼짐으로 인식하며, 예전 SP1 선택을 지원 장비 선택으로 바꾸지 않습니다. 기존 지형명·도움말·추가 전투 자막 등의 한글 표시 수정과 추가 파일럿 정신기 조정은 공통 적용됩니다. 기존 파일럿의 정신기는 유지합니다. SP 1 옵션은 제거했습니다. 이전 8옵션 적용본의 256가지 조합도 업데이트할 수 있습니다. 최초 적용 전에 변경 구간만 `.oggbak`에 저장하며, **처음 상태 복원**으로 되돌릴 수 있습니다.

| 옵션 | 내용 |
| --- | --- |
| 25편성·추가 시나리오 | 3화부터 전이 대화, 4~31화 분산 합류, 추가 편성 밸런스·본편 연결 및 후속 대사 |
| 숨겨진 요소 자동 습득 | 6·13·25·30화 숨김 보상 조건 해제 |

| 전투 보상 | PP 2배, 자금 +20% |
| 적 강화 | 전투 능력치 +5, 기체·무장 개조 +2, 기본 HP 2만 미만 +10% |

25편성 시나리오는 새 게임에서 시작하세요. 이미 받은 보상이나 합류한 인물은 옵션을 해제해도 세이브에서 삭제되지 않습니다. 이벤트가 지난 세이브에 보급이 소급 지급되지는 않습니다. 패치 후 상태 저장을 불러오지 말고 게임을 새로 부팅하세요. 자세한 내용은 [사용 안내](docs/사용안내.txt)를 참고하세요.

## 빌드

Windows PowerShell 5.1 이상과 .NET Framework C# 컴파일러를 사용합니다. Python은 패처 실행·빌드에 필요하지 않습니다.

1. 해당 버전 릴리즈 ZIP에서 `patcher/OGG_options.bin`을 준비합니다.
2. 저장소 루트에서 실행합니다.

```powershell
.\build.ps1 -PackPath 'C:\Downloads\SRWOGG_Options_kr_v20261107\patcher\OGG_options.bin'
```

`dist`에 EXE와 BIN이 생성됩니다. 패치 데이터의 SHA-256과 1,024개 조합을 자동 검사합니다. 릴리즈 EXE와 직접 빌드한 EXE의 파일 해시는 컴파일 시각 등에 따라 다를 수 있습니다.

## 소스 구성

- `src/OggOptionsPatcher.cs`: UI, 입력 검증, 10개 옵션 합성, 구간 백업·복원, 명령행 검증.
- `build.ps1`: 패처 빌드와 자체 검사.
- `tools/work_ogg`: 패치 제작·시나리오·밸런스·한글화·분석·네이티브 검증 Python 소스.
- `tools/work_ogs`: 위 소스가 참조하는 한글 코덱과 R5900 검사기 소스.
- `docs`: 사용 안내, 패치 정보, 검증 결과.

Python 제작 도구는 작업 과정을 보존한 소스입니다. 일부 도구는 예전 단계의 파일명·중간 산출물·적용 전 상태를 전제로 하므로 현재 ISO에 그대로 순서대로 실행하면 안 됩니다. 관련 내용과 재현 범위는 [제작 도구 안내](tools/README.md)를 참고하세요.

## 검증 범위

이번 대사 보강은 실제 게임 문자열·이력 조회 146건, 대사 이력 2,267항목, 새 장면 5개의 중복 방지와 영구 저장 데이터 복원 후 재실행 방지를 확인했습니다. 1,024개 조합을 메모리에서 합성하여 새 장면의 선택·해제 5,120건, 29화 정비 옵션 독립성 및 다른 기능의 변경값 보존을 검사했습니다. 조기 입수는 시나리오·8종 보급 ON/OFF 8가지 구성에서 실제 게임 루틴으로 독립 지급·중복 방지를 확인했습니다. 패처 자체 검사와 이전 8옵션 256조합, v20261106.1~.4 각 128조합, v20261106.5의 512조합 인식도 통과했습니다. [이번 검증 결과](docs/validation-v20261107.json)를 제공합니다.

이번 버전에서는 1,024개 조합을 ISO에 반복 쓰는 검사를 하지 않았습니다. PCSX2 플레이 테스트는 사용자가 진행합니다. VM의 저장 데이터 복원은 실제 메모리카드 I/O나 전편 플레이 검증이 아닙니다. 이전 기능의 검사 범위는 각 버전의 문서에 기록되어 있습니다.

지원 원본은 크기 `4,666,294,272`바이트이며 SHA-256은 다음과 같습니다.

```text
e819f1e524513bc7e273b004ba02e3977dd4fff365a5887b4eb1c8a9fc9d1e04
```

게임 ISO·BIOS·메모리 덤프·세이브 파일은 저장소와 릴리즈에 포함하지 않습니다. 릴리즈에는 적용에 필요한 패치 데이터만 제공합니다.
